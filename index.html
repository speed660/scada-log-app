    GitHub

    Журнал сохраняется в файл приватного репозитория GitHub и подтягивает записи других диспетчеров. Токен: GitHub → Settings → Developer settings → Fine-grained tokens, доступ только к этому репозиторию, право Contents: Read and write. Токен хранится в этом браузере только зашифрованным паролем, при открытии страницы пароль спрашивается один раз. В файл журнала и в резервную копию токен не попадает. Пароль не восстанавливается: если забыл, подключи GitHub заново.

    Каждое изменение отправляется в GitHub через пару секунд, новые записи других диспетчеров подтягиваются раз в минуту. Без связи журнал работает в браузере и отправит накопленное, когда связь появится.

    «Заблокировать» убирает токен из памяти, например перед сдачей смены. Записи продолжают сохраняться в браузере и уйдут в GitHub после ввода пароля.

    Резервная копия

    Разовая копия всех данных на флешку, другой компьютер или телефон. В отличие от рабочего файла, она сама не обновляется. Загрузка добавляет записи из копии к текущим и ничего не удаляет.

    Списки для формы

    «Ручной», «угол» и «наклон» сразу ставят отметку «вернуть в исходное», а «угол» и «наклон» ещё открывают поле угла. Новые пункты можно добавлять и прямо в форме кнопкой «+ Своё».

    Станция и трекеры

    Нужно, чтобы форма подсказывала угол по солнцу. Координаты станции можно взять в Google Maps: нажми правой кнопкой на станцию, первая строка в меню и есть широта и долгота. Её можно вставить целиком в поле «Широта».

    GCR: ширина стола, делённая на расстояние между рядами. Если указать, расчёт учтёт backtracking (утром и вечером стол выравнивается, чтобы ряды не затеняли друг друга). Если на станции backtracking выключен, оставь пустым. Предел угла и знак возьми из паспорта трекера или с экрана SCADA.
